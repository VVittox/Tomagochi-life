# Tamagotchi Life — объединённый проект (этапы 1 + 2)

Проект для МШП, команды **I use Arch BTW**. Основан на двух версиях из архива
[VVittox/Tomagochi-life](https://github.com/VVittox/Tomagochi-life), презентации
«Занятие 05. Проект Тамагочи этап 2» и командном PlayBook.

**Запуск происходит только через один файл — `main.py`.** Остальные `.py` — модули игры, а не альтернативные точки входа.

## Как запустить

Нужен Python **3.10 или новее**.

```bash
python -m venv .venv
```

Активируйте окружение:

- **Windows (PowerShell):** `.venv\Scripts\Activate.ps1`
- **Windows (cmd):** `.venv\Scripts\activate.bat`
- **macOS / Linux:** `source .venv/bin/activate`

Затем в папке проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

Если устанавливать зависимости нельзя, можно запустить `python main.py` сразу:
`colorama` необязательна и нужна только для цвета сообщений.

## Возможности

- Создать кошку (**Cat**) или собаку (**Dog**) с именем.
- Кормить, играть, укладывать спать и будить питомца.
- Пропускать время: день и ночь, голод, энергия и настроение изменяются.
- Кошка и собака ведут себя по-разному (особенно при игре).
- Сохранить в `save.json`, выйти и загрузить снова (включая вид и время).
- Без сохранения, с битым JSON и при неправильном вводе игра не падает.
- Если голод становится 10 или настроение 0, игра заканчивается; можно начать новую.

Характеристики лежат в диапазоне **0–10**; большее значение голода — хуже.
При кормлении проходит **30 минут**, при игре — **1 час**, при укладывании спать — **1 час**, при пробуждении — **15 минут**.
Полностью прошедший час увеличивает голод на 1; при бодрствовании энергия и настроение падают на 1, во сне энергия восстанавливается на 2.
Часы хранятся только в `GameClock`, не в `Pet`. Неполные часы не теряются после сохранения.

## Что перенесено из старой и новой частей

| Источник из архива | Где теперь используется |
|---|---|
| `Apart.py`, `Bpart.py`, `A.py` | `pets/pet.py`: состояния, `_clamp`, кормление, игра, сон |
| `main(Old).py`, `Cpart.py` | `game.py` + `pets/pet.py`: меню, течение времени, изменение характеристик и конец игры |
| `Pets/cat.py`, `Pets/dog.py` | `pets/cat.py`, `pets/dog.py`: наследование и различное поведение |
| `clock.py` | `clock.py`: независимые часы с минутами |
| `Dpart.py` | `exceptions.py`: ошибки и проверки |
| `Epart.py`, `Main.py` | `game.py`, `main.py`: единое рабочее меню и запуск |
| `Save.py`, `storage.py` | `storage.py`: настоящее сохранение в JSON, а не в памяти |

Старые черновики и второй `main(Old).py` в рабочую папку специально **не включены**, чтобы не было конкурирующих версий.
Исходный архив и история разработки остаются в GitHub-репозитории команды.

## Как проверить

```bash
python -m unittest discover -s tests -v
```

Проверяются создание Cat/Dog и различия в `play()`, время, границы характеристик,
сохранение и восстановление данных, отсутствие/повреждение файла и консольный запуск.

### Сценарий показа для МШП

1. Запустить `python main.py`, создать кошку, сыграть с ней.
2. Выбрать «Новая игра», создать собаку, сыграть и показать отличие.
3. Пропустить 1.5 часа и показать часы и характеристики.
4. Сохранить игру пунктом 7, выйти пунктом 0.
5. Запустить повторно, выбрать загрузку и проверить имя, вид, статистики и часы.
6. Показать, что при отсутствии `save.json` предлагается новая игра, а повреждение файла не завершает программу.

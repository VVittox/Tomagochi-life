Проект «Тамагочи» — Этап 1

Промышленное программирование. Консольный виртуальный питомец на Python: класс, состояние, действия, игровое время.

1. Сжатый план проекта

Что делаем: консольный виртуальный питомец.

Ядро — класс Pet:

  • Состояние: name, hunger, mood, energy — все значения в диапазоне 0..10.
  • Действия: feed(), play(), sleep(), wake_up().
  • Время: pass_time(hours), wants_to_sleep(hour).
  • Вывод: __str__().

Правила:

  • Значения никогда не выходят за пределы 0..10.
  • Ночью (22:00–06:00) питомец хочет спать.
  • Сон повышает энергию, кормление снижает голод, игра повышает настроение.
  • Ошибки не должны ронять программу (свои исключения + try/except в меню).

Командные роли:

РольОтветственность
AСостояние класса Pet, __str__
Bfeed(), play(), sleep(), wake_up()
CИгровое время, pass_time(), wants_to_sleep()
DИсключения и проверки
EМеню и основной цикл
FТесты
G / HСборка проекта и сдача

Порядок работы:

  1. A пишет каркас класса.
  2. B добавляет действия.
  3. C добавляет время.
  4. D добавляет исключения.
  5. E собирает меню.
  6. F тестирует.
  7. G/H собирают всё в один файл и сдают.

Сдача: рабочий файл в Eduapp + сообщения в RocketChat.

Шаг 2. Класс Pet — каркас (роль A)

class Pet:
    MIN_VALUE = 0
    MAX_VALUE = 10

    def __init__(self, name):
        self.name = name
        self.hunger = 5
        self.mood = 5
        self.energy = 5
        self.is_sleeping = False
        self.hour = 12  # игровое время

    def _clamp(self):
        self.hunger = max(self.MIN_VALUE, min(self.MAX_VALUE, self.hunger))
        self.mood = max(self.MIN_VALUE, min(self.MAX_VALUE, self.mood))
        self.energy = max(self.MIN_VALUE, min(self.MAX_VALUE, self.energy))

Шаг 3. Действия (роль B)

    def feed(self):
        if self.is_sleeping:
            raise PetAsleepError(f"{self.name} спит и не может есть")
        self.hunger -= 3
        self.mood += 1
        self._clamp()
        print(f"{self.name} покушал. Голод: {self.hunger}")

    def play(self):
        if self.is_sleeping:
            raise PetAsleepError(f"{self.name} спит и не может играть")
        if self.energy < 2:
            raise PetTooTiredError(f"{self.name} слишком устал для игры")
        self.mood += 2
        self.energy -= 2
        self.hunger += 1
        self._clamp()
        print(f"{self.name} поиграл. Настроение: {self.mood}")

    def sleep(self):
        if self.is_sleeping:
            print(f"{self.name} уже спит")
            return
        self.is_sleeping = True
        print(f"{self.name} лёг спать")

    def wake_up(self):
        if not self.is_sleeping:
            print(f"{self.name} уже бодрствует")
            return
        self.is_sleeping = False
        print(f"{self.name} проснулся")

Шаг 4. Время (роль C)

    def wants_to_sleep(self, hour):

        for _ in range(hours):
            self.hour = (self.hour + 1) % 24

Шаг 6. Меню и основной цикл (роль E)

def menu(pet):
    while True:
        print("\n--- Тамагочи ---")
        print("1. Показать состояние")
        print("2. Покормить")
        print("3. Поиграть")
        print("4. Уложить спать")
        print("5. Разбудить")
        print("6. Пропустить время")
        print("0. Выход")
        choice = input("Выберите действие: ").strip()

        try:
            if choice == "1":
                print(pet)
            elif choice == "2":
                pet.feed()
            elif choice == "3":
                pet.play()
            elif choice == "4":
                pet.sleep()
            elif choice == "5":
                pet.wake_up()
            elif choice == "6":
                hours = int(input("Сколько часов пропустить? "))
                pet.pass_time(hours)
            elif choice == "0":
                print("Пока!")
                break
            else:
                print("Неверный выбор")
        except PetError as e:
            print(f"Ошибка: {e}")
        except ValueError:
            print("Ошибка: введите число")

if __name__ == "__main__":

4. Тестирование (роль F)

  1. Создать питомца → показать статус.
  2. Покормить → hunger уменьшился.
  3. Поиграть → mood вырос, energy упал.
  4. Уложить спать → статус «спит».
  5. Попробовать покормить спящего → PetAsleepError, программа не падает.
  6. Пропустить 15 часов → питомец захочет спать.
  7. Ввести букву в меню → ошибка обрабатывается.
